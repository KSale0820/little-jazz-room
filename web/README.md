# Little Jazz Room — Phase 1 app

Mobile-first Vite + React + TypeScript prototype. Seed data lives in `src/data/jazz-seed-content.json` (copy of repo root).

```bash
npm install
npm run dev
```

Open http://localhost:5173/ — use devtools device mode at **390px** width for phone layout.

See `PHASE1-TEST-RESULTS.md` for validation output.
