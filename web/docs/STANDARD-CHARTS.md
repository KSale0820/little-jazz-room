# Standard chart replacement

Tracks and Charts now show eight standards, with no recordings. Existing educational charts remain internally available for saved routines, exercise references, and old player links. No saved user data is removed.

These are chord-only practice changes, not melody lead sheets or transcriptions of a particular backing recording. Repeats are expanded to full choruses so navigation, looping, and the timer follow actual measure order. Sources sometimes show multiple variants: the iReal chart variant is used for Autumn Leaves, All the Things You Are, How High the Moon, Ornithology, and Oleo; the numbered analysis is used for Blue Bossa and Song for My Father. Sandu uses the cited common solo changes rather than the head's pedal and breaks. Song for My Father's recorded breaks are not encoded as rests.

Sources are retained on each chart and linked from the practice player. No source artwork, melody, lyrics, or audio is bundled. New chord qualities retain sixths, minor-major sevenths, and altered dominant symbols instead of silently dropping them.
