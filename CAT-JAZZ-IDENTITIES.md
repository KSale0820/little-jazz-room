**Artwork acceptance:** read `FINAL-DESIGN-LOCK.md`. Musical props are stage context; idle cats do not need to carry an instrument at all times. Provide each cat's instrument as text on the chooser and (where visibly integrated/QA-approved) a separate prop in the Home room. The user specifically approved Milo's sunglasses and playful jazz signifiers but requested **minimum visual clutter**.

**Consistency:** same selected cat ID and coat/build on Home and Profile; optional lower Practice companion uses that same ID. No generic calico should appear when user has selected Milo. A cat can respond to a completed practice session with one short natural movement, but no six-pose sprite sheets needed.
